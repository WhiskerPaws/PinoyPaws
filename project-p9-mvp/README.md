# Project P9 MVP v0.1

Temporary internal codename for the rewards/performance marketplace.

## MVP scope
- User accounts
- Business accounts
- Campaigns
- Campaign participation
- Verification states
- Wallet + transaction ledger
- Withdrawals
- Admin controls (planned)

## Build order
1. Database
2. Authentication
3. User dashboard
4. Campaign engine
5. Business dashboard
6. Verification
7. Wallet/transactions
8. Admin

## Important business rule
Campaign rewards must be funded/reserved before a campaign becomes active. User deposits are not part of the model.

## Status
Scaffold only. No production payments or withdrawals are enabled.
